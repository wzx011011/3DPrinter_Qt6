# Roadmap: v5.8 Submodule Baseline Alignment + Hollow Editing

**Defined:** 2026-07-25
**Status:** Completed (all 4 phases delivered, 2026-07-25)
**Verification gate:** canonical build green; multiPlateFullStateRoundTrip,
test_slice_produces_gcode_file, mmuSegmentationPaintFeedsSlice, and the three
v5.0 dialog regression locks all PASS.

This milestone was discovered mid-merge rather than planned up front: the
v5.7→main merge pinned the submodule to the 4cb3b9ce baseline while
origin/main's ProjectServiceMock.cpp had already migrated to 0632bae8's API
surface, breaking the build. Phase 212 repaired that; Phases 213–215 then
delivered the two feature gaps the post-merge code-truth audit surfaced.

## Phase 212 — Submodule 0632bae8 Baseline Alignment

**Status:** Complete · **Requirement:** BASE-01..04 · **Commit:** `b19087b`

Created `0632bae8` + 5 OWzx-compat patches on submodule branch
`owzx-cgal54-on-0632` (pushed to `github-fork`):

1. CGAL 5.4 hole refinement (port segment() `#if` flip from 4cb3b9ce; 4cb3's
   standalone CGAL `repair()` dropped — 0632 moved mesh repair to admesh).
2. mcut `frontend.h` missing `<chrono>` include (MSVC 14.50.35717 dropped the
   transitive include via `<future>`).
3. `TriangleMeshDeal` (loop subdivision) ported from 4cb3b9ce, adapted to
   0632's stricter `igl::loop` PlainObjectBase overload (Map<const> → copy).
4. `Format/DRC.hpp` + stub `DRC.cpp` (draco not provisioned;
   store/load_drc → false; STL export unaffected).
5. `TriangleMeshDeal.cpp` igl::loop overload adaptation.

ProjectServiceMock.cpp adapted to 0632's API surface:
`ModelVolume::split(1, false)` → `split(1)`; `ModelInstance::auto_drop`
removed (dropObjectToBed/objectAutoDrop/setObjectAutoDrop simplified).

## Phase 213 — MMU Config-Driven Colours and Count

**Status:** Complete · **Requirement:** MMU-01..03 · **Commit:** `11a6afe`

`ProjectServiceMock` gains `plateFilamentColours()` + `filamentCount()`
(reading the `filament_colour` coStrings option). `EditorViewModel` adds
`mmuExtruderColors` Q_PROPERTY and rebinds `mmuExtruderCount` to the
configured count. PreparePage.qml binds swatch colours to the config list
(fallback palette for pre-load) and shows an honest single-material notice
when `mmuExtruderCount <= 1`.

## Phase 214 — Hollow Drain Hole Data and Logic Layer

**Status:** Complete · **Requirement:** HOLLOW-01..03,06 · **Commit:** `59eeffa`

`ProjectServiceMock` reads/appends/clears `ModelObject::sla_drain_holes`.
`EditorViewModel::placeHollowPoint` casts the world ray via the shared
SceneRaycaster and appends a `sla::DrainHole` at the mesh-local intersection.
`hollowMarkerData` flattens holes into a packed world-space disc-fan vertex
stream. `deleteSelectedHollowPoints` clears the object's holes (was TODO).

## Phase 215 — Hollow Viewport Routing and Render

**Status:** Complete · **Requirement:** HOLLOW-04,05, VER-01..04 · **Commit:** `5b7b8b4`

`RhiViewport` routes GizmoHollow left-click to `hollowPickRequested` (stage-1
pick + world ray). `RhiViewportRenderer` uploads the marker stream
(libslic3r Y/Z → scene swap) and renders translucent red discs gated to
GizmoHollow. PreparePage.qml wires `hollowMarkerData` + `onHollowPickRequested`.
Regression gates re-verified green.
