# Requirements: v5.8 Submodule Baseline Alignment + Hollow Editing

**Defined:** 2026-07-25
**Core Value:** Repair the build break introduced by the v5.7→main merge
(the submodule was pinned to the 4cb3b9ce baseline while origin/main's
ProjectServiceMock.cpp had already migrated to 0632bae8's newer API
surface), then deliver two source-truth feature gaps surfaced by the
post-merge code-truth audit: MMU extruder colours/count driven from the
active print config, and an interactive Hollow (drain hole) editing gizmo.
**Status:** Active.

## BASE: Submodule Baseline Alignment

- [x] **BASE-01** (Phase 212): `third_party/OrcaSlicer` points to a commit
  on `0632bae8` (origin/main's expected baseline) that carries the OWzx-local
  compat deltas previously held only on `4cb3b9ce`. The main repo builds and
  links `OWzxSlicer.exe` + all test exes with the new pointer.
- [x] **BASE-02** (Phase 212): The CGAL 5.4 hole-refinement fix (segment()
  `#if` flip) is present on the new baseline; MeshBoolean compiles on CGAL 5.4.
- [x] **BASE-03** (Phase 212): `ProjectServiceMock.cpp` uses only APIs that
  exist on `0632bae8`: `ModelVolume::split` (1-arg), `ModelObject::split`
  (1-arg via the persistence adapter), and no `ModelInstance::auto_drop`
  references (the member was removed on 0632).
- [x] **BASE-04** (Phase 212): OWzx-local libslic3r extensions absent from
  `0632bae8` are ported as submodule commits: `TriangleMeshDeal` (loop
  subdivision, adapted to 0632's stricter `igl::loop` overload) and
  `Format/DRC.hpp` + a stub `DRC.cpp` (draco not provisioned;
  `store_drc`/`load_drc` return false so the STL export path stays functional).

## HOLLOW: Drain Hole Editing

- [x] **HOLLOW-01** (Phase 214): `ProjectServiceMock` reads/appends/clears
  `ModelObject::sla_drain_holes` (对齐 upstream `sla::DrainHoles`) through a
  QML-friendly variant form; 3MF persistence rides upstream serialization.
- [x] **HOLLOW-02** (Phase 214): `EditorViewModel::placeHollowPoint` casts a
  world ray through the picked object's volumes via the shared
  `SceneRaycaster`, converts the world normal to mesh-local, and appends a
  `sla::DrainHole` at the mesh-local intersection.
- [x] **HOLLOW-03** (Phase 214): `hollowMarkerData` Q_PROPERTY +
  `hollowDataChanged` signal flatten the selected object's holes into a
  packed world-space disc-fan vertex byte stream for the renderer.
- [x] **HOLLOW-04** (Phase 215): `RhiViewport` routes a GizmoHollow left-click
  to `hollowPickRequested` (stage-1 AABB pick + world ray), forwarded by QML
  to `placeHollowPoint`.
- [x] **HOLLOW-05** (Phase 215): `RhiViewportRenderer` uploads the marker
  stream to `m_hollowMarkerBuffer` (libslic3r Y/Z → scene swap) and renders
  translucent red discs gated to GizmoHollow (mode 8), after the paint
  overlay.
- [x] **HOLLOW-06** (Phase 214): `deleteSelectedHollowPoints` actually clears
  the selected object's drain holes (was a TODO stub).
