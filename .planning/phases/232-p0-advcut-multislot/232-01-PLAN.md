## Plan 1 (single batch)

### Task 1 — CIRC-03: AdvancedCut execution wiring

Verified breaks:
- `EditorViewModel::advCutSelected()` (EditorViewModel.cpp:2080-2156) is the only
  executor for groove (`cutObjectWithGroove`) and connector
  (`cutObjectWithConnectors`) cuts — zero QML callers.
- AdvancedCut panel's execute button binds plain `cutSelected()`
  (PreparePage.qml:3263) → always a plane cut.
- Connector click signal forwarded only in GizmoAdvancedCut mode
  (RhiViewport.cpp:752) while the connector toggle lives in the GizmoCut panel
  (PreparePage.qml ~2265) — UI states incoherent.

Fix (pre-studied, current code):
- The Cut panel (GizmoCut) already owns the mode selector cutMode 0=planar /
  1=groove (PreparePage.qml:2120-2132), groove params (:2142/2172), and the
  connector toggle (:2275-2279). The AdvancedCut panel (:3232-3267) binds the
  WRONG properties (cutAxis/cutPosition/cutKeepMode instead of advCutAxis/
  advCutPosition/advCutKeepBoth, EditorViewModel.h:786-789) and its execute
  button calls cutSelected().
- AdvancedCut panel rework: bind advCut* properties, add mode selector
  (planar / tongue-groove cutMode / connectors advCutConnectors), connector
  count readout (advancedCutConnectorCount), and execute → advCutSelected().
- Click routing stays GizmoAdvancedCut-only (RhiViewport.cpp:752) which is
  coherent once the toggle lives in the AdvancedCut panel too (shared VM
  state m_advCutConnectors).

  own preset name; colors from `activeFilamentColours()` / preset filament_colour.
- LeftSidebar slot Repeater binds slot index → per-slot API.
