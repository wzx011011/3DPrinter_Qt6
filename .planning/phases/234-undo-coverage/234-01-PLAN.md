# Phase 234 Plan — Undo Coverage And Fidelity

**Requirements:** UNDO-01..06
**Evidence:** `.planning/research/v5.16-GAP-BASELINE.md` P0 #8 + Undo coverage section

## Plan 1 (single batch)

Upstream truth: every user action takes a whole-model snapshot
(Plater::_take_snapshot incl. partplate_list, selection, gizmo state). Qt6 is
per-command; the gap is coverage + fidelity, not the mechanism.

### Task 1 — UNDO-01: delete-object undo restores the full object
- `DeleteObjectsCommand::undo` (UndoCommands.cpp:187-240) re-adds via
  `addObject(name)` — an empty object (ProjectServiceMock.cpp:6475-6497).
  Follow the mesh-snapshot pattern already used by Cut/Boolean/Drill commands
  (EditorViewModel.cpp:1658-2464): capture per-object volume meshes
  (QByteArray STL), volume types/names, instance transforms, plate index, and
  object config overrides in the command; restore via a new
  `ProjectServiceMock::restoreDeletedObject(snapshot)` that reinserts the full
  object at its old index. Redo deletes by captured index+identity, and must
  handle index shifts (delete by re-captured identity, not name).
- Same fix for `AddObjectCommand::redo` (UndoCommands.cpp:261-268).

### Task 2 — UNDO-02: volume delete enters the stack
- `VolumeDeleteCommand` is declared (UndoCommands.h:218-237) but never
  instantiated; `deleteVolume/deleteSelectedVolumesBySource`
  (EditorViewModel.cpp:4633-4702) bypass the stack. Push the command with
  volume mesh snapshot + volume metadata.

### Task 3 — UNDO-03: plate operations enter the stack
- New PlateCommand family (or one parametric command) snapshotting the plate
  list slice (names, locked, bed type, print sequence, spiral, object/instance
  membership, plate config) for add/delete/move/clone/lock/printable
  (EditorViewModel.cpp:6242-6369 today push nothing). Restore rebuilds the
  affected plates. Deep-clone object data for delete-plate undo (objects die
  with the plate).

### Task 4 — UNDO-04: painting enters the stack
- paintAtFacet (EditorViewModel.cpp:3461-3592) writes FacetsAnnotation with no
  command. Capture the touched facets + previous state per stroke
  (begin/endStroke coalescing already exists for transforms — mirror it),
  push a PaintCommand writing mv->supported_facets / seam_facets /
  mmu_segmentation_facets back.

### Task 5 — UNDO-05: paste fidelity + show/hide semantics
- Clipboard holds names only (EditorViewModel.cpp:5247-5328). Make it hold
  real object snapshots (same snapshot type as Task 1) so paste restores
  mesh/transform/overrides.
- Show/hide writes `inst->printable` (ProjectServiceMock.cpp:1759-1781) —
  clash with the printable toggle. Upstream show/hide is a view concept
  (GLVolume::visible). Introduce a separate visibility flag consumed by the
  viewport filter; stop writing printable from the show/hide menu.

### Task 6 — UNDO-06: layer ranges reach libslic3r
- ObjectLayersDialog CRUD lands in `m_mockLayerRanges` only
  (ProjectServiceMock.cpp:4223-4272). Bridge to
  `ModelObject::layer_config_ranges` (upstream GUI_ObjectLayers semantics:
  auto-shorten inserted ranges), keep mock arrays as UI mirror, ensure slicing
  consumes variable layer heights; 3MF round-trip via existing layer range
  persistence if present (verify store path writes layer_config_ranges —
  Model::objects serialization does; check our 3MF write path uses model
  serialization).
