# tests/ — 测试架构与换轨原则

本目录是 OWzx（OrcaSlicer→Qt6/QML 源真值迁移）的门禁测试层。canonical verify（`scripts/auto_verify_with_vcvars.ps1`）内嵌的 13 套件全部来自这里；各套件职责见 `.codex/rules/build-rules.md`。

## 换轨原则（S7，2026-10-15 成文）

> **任何正确的重构——重命名、提取 helper、重排版、换绑定写法——都不应该需要改测试。**
> 如果一次没有改变行为的改动让测试变红，错的不是改动，是测试锁错了东西。

这条原则是审计④章 S7（字符串锁分批降级）的执行标准。字符串锁（源码 `contains()` 断言）在行为安全网（Q14 QmlSmokeTests）建立之前曾是唯一的回归保护；现在行为网已立，字符串锁按下面的分类**分批降级**，而不是永久维持。

## 字符串锁分类与处置（S7 税则）

对任何一处源码字符串锁，先问：**它锁的是行为，还是格式？**

| 类别 | 例子 | 处置 |
|---|---|---|
| **行为/结构锁**（保留） | 符号/ID 存在（`Q_PROPERTY(bool hollowEnabled`、`\nvoid RhiViewport::renderMoveGizmo`）、信号→后端路由序列、诚实披露文案（"演示"家族、不可用披露）、**像素字面量**（`height: 36`、上游对齐的 `interval: 500`）、qrc/文件清单与缺席锁（已删路径不得回归） | **保留**。ID/像素锁是过渡期既定保留项（S7 裁定）；缺席锁不阻碍正确重构。 |
| **格式锁**（降级，2026-10-15 批次已清） | 模式串内嵌 `\n`+缩进、逐字空行结构、注释文本本身（"case 8 必须有某条注释"） | **迁移**到 `normalizedSource()` 白空间归一化匹配或直接删除（纯注释锁）。锁语句顺序/绑定关系，不锁缩进换行。 |
| **出现次数锁**（逐个降级中） | `count("X") >= 3`（三个面板各一处）、`count == 2`（恰好两条路径） | **迁移**为逐块断言（每个具名块各自 contains）或阈值放宽（`>= 1` + 结构锁）。数据契约类计数除外（i18n `unfinished == 0`、ConfirmDialog 自发信号 `== 0` 是行为，保留）。 |
| **文案精确锁**（迁移中） | `contains(qsTr("某句完整中文文案"))` | 优先**运行时行为断言**（QmlSmokeTests 实例化页面后走对象树查披露 token）；不能运行时覆盖的（对话框）保留为过渡并在锁注释标注 `S7-transition`。 |

## 落地机制

- **`QmlUiAuditTests::normalizedSource()`**：把任意空白串（缩进/换行/CRLF）折叠为单空格。新写"序列锁"一律 `normalizedSource(src).contains("token1 token2 ...")`；只有 ID/像素锁才直接用 `readSource()` 原文匹配。
- **`QmlSmokeTests`**：行为网本体（真实 QQmlEngine 加载 main.qml+10 页面，断言零 QML 错误 + S1 簇 NOTIFY 契约 + 绑定重求值）。字符串锁降级的目的地优先是这里——能实例化的表面，锁运行时属性/文本，不锁源码。
- **新增锁的准入**：往 QmlUiAuditTests 加新 `contains()` 前，先问能否写成 QmlSmokeTests 的行为断言；确实只能锁源码的，按上表归类并写明锁的是什么（行为还是格式）。

## 迁移节奏（S7 分批）

S7 是分批降级而非一次性替换：每批只迁一类（格式 → 次数 → 文案），每批过 canonical verify。已落地批次记录在提交历史（`test(audit)` 前缀 + S7 标注）。Q7/Q11/U 批已删项的锁已转为缺席锁（吃红利），这类锁（"已删组件不得回归"）是合法永久锁，不在降级之列。
