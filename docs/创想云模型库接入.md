> 决策记录：[依赖与协议边界审计.md](依赖与协议边界审计.md) §Model Mall 解除阻塞决策记录（2026-10-23）
> 参考实现：官方开源 [CrealityOfficial/CrealityPrint](https://github.com/CrealityOfficial/CrealityPrint)（AGPL-3.0，与本项目上游 OrcaSlicer 同源同许可）

## 1. 架构

```
BBLTopbar ModelStore 按钮 ──▶ main.qml modelLibraryPanelLoader（source-URL Loader，
                                        WebEngine 缺失时仅此塌陷）
        │
ModelLibraryPanel.qml ──── WebEngineView（共享 defaultProfile：UA + 登录 cookie 持久化）
        │  ▲                        加载 cp.crealitycloud.cn|com 模型库
        │  └─ window.handleStudioCmd(json)（runJavaScript）
        │
CXSWGroupInterface shim（运行时注入：qwebchannel.js(选装于 qml_web.qrc) + 转发层）
        │  window.CXSWGroupInterface.postMessage(json) → WebChannel
        ▼
ModelLibraryBridge（owzx_app_core）
  ├─ 命令：get_account_info / trigger_login_check / get_client_id
  ├─ 下载：3mf_download_start / models_download_start → ModelDownloadService
  ├─ 状态：*_download_state / *_download_delete
  ├─ 导入：3mf_download_import → load-project；models_download_import → load-files
  └─ linkType 分流：1=需登录（回发 trigger_login_check）403=系统浏览器 404=token 失效
        │
BackendContext：装配开关 Cloud/Backend=mock|creality（默认 mock）
  ├─ CrealityAuthService（OAuth：本地 15888 回调 + oauthLogin 换 token，QSettings 持久化）
  ├─ CrealityCloudService（真 ICloudDataPlane：账号面真，设备/同步面诚实空置）
  └─ 导入路由：topbarOpenProject / topbarImportModel / addFilesToCurrentPlate + 切 3D 页
```

## 2. 协议要点（移植自官方开源客户端，验证于 2026-10-23）

- 端点：`api/cp.crealitycloud.cn|com`（Release），配置层 `CrealityCloudConfig` 唯一维护
- 请求头：`__CXY_TOKEN_ / __CXY_UID_ / __CXY_OS_LANG_ / __CXY_APP_ID_=creality_model /
  __CXY_PLATFORM_=11 / __CXY_DUID_ …`（Qt 6 在线上会把自定义头转小写——RFC 允许，已验证可用）
- JS 桥：`CXSWGroupInterface.postMessage`（网页→壳）与 `handleStudioCmd`（壳→网页）
- 登录：**页内完成**（商城头部自带 登录/注册），cookie 存共享 WebEngineProfile；
  独立登录页 `www.creality.com/pages/login` 已随官网改版下线（404），
  oauth 换 token 链路保留用于账号面
- 下载：`*_download_start` 消息带 `{url,fileId,fileFormat,name}`；
  落盘 `<downloadPath>/<userId>/models/<modelId>/` 与 `3mfs/`，重名 `(n)` 规则

## 3. 风险与已登记限制

| 项 | 说明 | 对策 |
|---|---|---|
| 服务端无契约 | 端点/桥协议/风控可变（clientId 来自开源代码） | 全部收敛在 CrealityCloudConfig；登录功能独立；长期解=商务授权 |
| 端点漂移实例 | 官网登录页 404（本次已遇到并改配置层解决） | 端点全配置化 |
| token 明文 QSettings | 与项目 aiApiKey 现状一致 | 审计文档入册；TODO keychain |
| WebEngine 兼容 | 本机曾调查过 Chromium 线程问题 | 动态加载 + OWZX_DISABLE_WEBENGINE=1 降级（面板/登录/对话全部隔离在 source-URL Loader） |
| JS 桥注入时序 | qmlcachegen 不接受 userScripts 值类型数组 | 运行时注入（LoadStarted+LoadSucceeded 双保险 + 幂等 shim + 待发队列）；compiler 支持后回迁 DocumentCreation |
