> 更新：2026-11-03，按代码核对。2026-03 版的逐文件证据清单基于已废弃的 `third_party/CrealityPrint` 路径，已删除（见 git 历史）；本文保留仍然有效的结论、阻塞登记表和决策记录。
> 代码中有多处注释引用本文（`CMakeLists.txt`、`CrealityCloudService.h`、`HomePage.qml`、`MonitorPage.qml`、`SelectMachineDialog.qml`、`QmlUiAuditTests.cpp`），改动章节名时同步检查。

## 1. 边界结论

上游界面层里有一部分能力依赖闭源插件、外部服务或专有协议，不能承诺"完全复刻"。按三类处理：

| 类别 | 含义 | 本项目中的模块 |
|---|---|---|
| 直连迁移 | 开源可控，直接承接 | 切片、3MF、G-code 预览、预设、校准中的切片类条目、Web 容器宿主（QtWebEngine） |
| 包装适配 | 宿主可迁，但依赖外部服务或协议 | 创想云账号与模型库（已接入）、局域网设备（已接入）、摄像头拉流（FFmpeg 已链接） |
| 暂缓或受限 | 依赖闭源插件或未公开协议 | `bambu_networking` 专有能力、云端设备 MQTT、云打印与云任务、固件 OTA |

原则：**不允许 Mock 假成功**。外部能力不可用时，界面必须明确显示不可用，不得用静态数据、定时器假进度或"已连接"文案掩盖。

## 2. 当前构建的阻塞登记表

每一项必须同时具备：界面上的不可用说明 + 防止假功能复活的回归测试。两者缺一视为登记失效。解除阻塞时同步删除对应说明和断言。

| 能力 | 阻塞原因 | 用户可见状态 | 回归测试 |
|---|---|---|---|
| 固件 OTA | 无版本查询、OTA 协议、包校验与重启状态机 | `FirmwareDialog` 显示"固件更新当前不可用"及原因 | `QmlUiAuditTests::firmwareDialogDoesNotSimulateOta` |
| 设备 SD 卡文件（演示后端） | 演示后端无文件系统通道；LAN 后端已有设备文件管理（`MoonrakerDeviceService`） | `MonitorPage` SD 页在演示后端下显示不可用 | `QmlUiAuditTests::monitorSdCardPanelIsExplicitlyUnavailable` |
| 摄像头状态 | FFmpeg 已链接，`CameraStream` 能真实解码；但 `CameraServiceMock` 状态机仍为模拟时序 | 无 URL 时保持断开/错误态，不渲染假画面 | Monitor 审计断言（连接状态不伪造在线） |
| 多机调度与云任务 | 无云账号设备任务协议 | `MultiMachinePage` 只能查看并跳转到监控页，无伪发送/暂停/取消 | `QmlUiAuditTests::multiMachineViewRoutesToMonitorIdentity` |
| 硬件类校准（调平、振动补偿等） | 需真实设备通道 | 校准列表中标注不可用原因，不留可点的假入口 | `QmlUiAuditTests::calibrationAndParameterControlsUseHonestLocalSemantics` |
| 设备自动上传、云备份 | 无设备传输通道与云服务 | 偏好设置中相应分组显示不可用 | `QmlUiAuditTests::deadControlEliminationAudit` |
| OpenVDB 相关流程 | OpenVDB 未链接（`CMakeLists.txt` 已移除开关） | 相关入口不暴露假完成状态 | 恢复前须先解决 OpenVDB 构建 |

## 3. 决策记录

### 3.1 模型库解除阻塞（2026-10-23）

**结论**：模型库走真实接入，"禁止 Mock 假成功"不变。实现见 [创想云模型库接入.md](创想云模型库接入.md)。

**依据**：

- Creality Print 已官方开源（AGPL-3.0，`CrealityOfficial/CrealityPrint`），其 `WebModelLibraryView`、`LoginDialog`、OAuth 回调和 `__CXY_*` 请求头构成可引用的远程契约。本项目上游 OrcaSlicer 同为 AGPL-3.0，移植无新增许可义务。
- 模型库链路不依赖 `bambu_networking`。Bambu 遗留的 `ModelMall`（指向 makerworld）不移植。

**边界**：

- 技术路线：QtWebEngine 加载 `cp.crealitycloud.cn|com` + WebChannel 桥（协议名 `CXSWGroupInterface` / `handleStudioCmd` 保持原样）+ 原生下载与导入。
- 命名：新组件用 `CloudModelLibrary*` / `CrealityCloud*`；`ModelMall*` 旧命名继续禁止（`QmlUiAuditTests::legacyDeadCodePagesRemoved` 的 MALL-01 断言保留）。
- 云预设同步、云打印、设备 MQTT 不在本次解除范围。

**接受的风险**：

1. 服务端无契约承诺：端点与 clientId 取自开源代码，可能变更或被风控。对策：全部集中在 `CrealityCloudConfig`；长期解为商务授权。
2. token 以明文存 QSettings（与 `aiApiKey`、`aiControlToken` 一致，项目尚无 keychain）。
3. WebEngine 稳定性：动态加载，`OWZX_DISABLE_WEBENGINE=1` 可整体关闭，面板崩溃不影响主流程。

### 3.2 局域网设备解除阻塞（2026-10-23，仅 LAN）

**结论**：Creality Print 的局域网设备实现（mDNS `_creality<类型码><端口>` 发现、`/info` 探测、4408 ws://9999 状态与控制、Moonraker HTTP 上传与启动）为完整开源实现，无闭源依赖，按"直连迁移"承接。实现见 [LAN打印机接入.md](LAN打印机接入.md)。

云端设备通道（`CloudDeviceMqttSession`、OSS 上传）仍为外部协议，维持暂缓。

## 4. 网络接入的安全约束

- 模型库下载：网页消息里的路径字段逐个过滤为单一文件名、拒绝可执行扩展名、最终路径必须位于下载根目录内、远程地址只接受 https（`ModelDownloadService`，2026-11-03）。
- OAuth 回调：协议无 `state`，只在用户发起登录时监听、收到第一个 code 即停止（`OAuthCallbackServer`，2026-11-03）。残余风险见追踪文档 P8。
