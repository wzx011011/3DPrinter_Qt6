## 0. 执行方式：动态工作流逐里程碑推进

- **形态**：每个里程碑一个 workflow run，串行流水线（唯一构建目录 `build/` 的项目规则排除了并行 worktree 方案）。
- **每项节奏**：实施员（读规格→实现→git commit）→ verify 门禁（`auto_verify_with_vcvars.ps1`，确定性退出码，失败喂回实施员，每项最多 3 轮）→ bench 门禁（触及性能路径的项加跑 `run_stage_bench.ps1`，按 `docs/perf-baseline.md` 稳定锚点规则判定回退 ≤~10%）→ 根治复核员（独立上下文读 diff，对照审计条目"为什么不是补丁"意图）。
- **失败隔离**：单项 3 轮仍红 → 标记 blocked 跳过；同文件域的依赖项随之跳过，独立项继续。
- **提交纪律**：每子项一提交，conventional commits 风格；只 `git add` 本项改动文件（工作树常驻他人未提交 WIP 与用户自行删除的文档，严禁 `git add -A`）。
- **运行约束**：verify 会全机杀 cmake/ninja/link（Q4 修复前）——run 期间请勿手动构建；run 出错用 AmendWorkflow 修订续跑（未变项零成本缓存）。
- **验收口径**：Q13a 落地前按"9 阻塞套件全绿 + 脚本 exit 0"判定（审计报告 ④ 章引言口径说明）；转阻塞后升为全量。

## 1. 全局规则（贯穿所有里程碑）

1. 唯一构建：`powershell -ExecutionPolicy Bypass -File scripts/auto_verify_with_vcvars.ps1`；**凡改 C++/QML 源码、测试或构建脚本必跑**（AGENTS.md 自测常备规则，非可选）。
2. 触及模型加载 / meshData / 场景展开 / 拾取 / 切片 / 预览解析 / 渲染提交路径的项，加跑 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/perf/run_stage_bench.ps1`；稳定锚点相对 `docs/perf-baseline.md` 回退 ≤~10%，易变指标按该文档噪声规则判定。
3. 触及切片链路（SliceService / PreviewViewModel / EditorViewModel / `src/cli/*` / 两个 ServiceMock / 子模块指针 / PerfBench / 门禁文件）会自动触发切片回归门禁（正确性 + 效率双层），属预期成本。
4. WIP 文件（RhiViewport / RhiViewportRenderer / CameraController 等）相关项一律排在 Q2 收尾提交之后。
5. 行为对齐上游（third_party/OrcaSlicer 为真值）；颜色归品牌自有（2026-10-07 裁定）。

## 6. 新增项详情（P 系列）

### P1 预览直传 GCodeProcessorResult（M0，1-2 天）

- **涉及文件**：src/core/services/SliceService.cpp/.h、src/core/viewmodels/PreviewViewModel.cpp/.h、tests/（相关套件）、tests/PerfBench.cpp（口径可选）
- **根因**：`print.export_gcode(targetPath, &result)`（SliceService.cpp:1172）已产出结构化 `Slic3r::GCodeProcessorResult`（上游预览直接消费的数据），当前只读一个时间标签即丢弃；预览页在 GUI 线程把刚写盘的 gcode 文本从头重解析（PreviewViewModel.cpp:905 loadGCodeForPreview → rebuildFromGCode），400k 模型 850ms、数百万 move 的极限 gcode 可达秒级白屏。上游 GCodeViewer::load_as_gcode 直消费 result（GCodeViewer.hpp:186/260），无文本往返。
- **实现**：(1) 切片线程把 result 以 `std::shared_ptr<GCodeProcessorResult>`（move 入堆，禁止值拷贝）随现有 invokeMethod 交付链带到 GUI；(2) PreviewViewModel 新增 `loadFromProcessorResult`，与 rebuildFromGCode 文本路径**共用同一 gcodePreviewData_ 构建函数**（单一结构双入口）；(3) 切片完成→预览走直传；`loadGCodeForPreview(filePath)` 独立 gcode 文件加载保留文本路径（其 bench 锚点 preview_parse_ms 不变）；(4) 构建完成后及时释放 result，评估与既有预览数据的重复存储。
- **风险**：跨线程移交生命周期；直传产物与文本路径产物逐字段对齐（层表 / move 表 / 角色 / 线宽）需测试锁定。
- **验收**：verify 全绿（触 SliceService 自动加跑切片回归门禁）；切片完成→预览就绪 <50ms（计时证据）；独立 gcode 加载 bench 锚点不变；内存峰值无显著上升。

### P2 鼠标导航上游对齐（M1，1-2 天）
