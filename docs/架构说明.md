## 1. 定位

OWzx Slicer 是 OrcaSlicer 的 Qt6/QML 重写：

- **引擎**：直接编译上游 libslic3r（`BUILD_LIBSLIC3R=ON`，不允许关闭），不改写。兼容改动以补丁形式应用，见 [上游基线与功能矩阵.md](上游基线与功能矩阵.md)。
- **界面**：上游的 wxWidgets GUI（`src/slic3r/GUI/`）不复用，用 Qt Quick 重新实现，行为以上游为准。
- **平台**：Windows + MSVC + D3D11（RHI），Qt 6.12.0。

## 2. 分层

```
QML（src/qml_gui/pages, panels, dialogs, components, controls）
   │  只做呈现、布局和交互接线；通过 Backend 单例拿到 ViewModel
   ▼
BackendContext（src/qml_gui/BackendContext.*）
   │  唯一装配点：创建全部 service 和 ViewModel，按 QSettings 选择设备/云后端
   ▼
ViewModel（src/core/viewmodels）
   │  页面状态、工作流编排、撤销命令；向 QML 暴露 Q_PROPERTY / Q_INVOKABLE
   ▼
Service（src/core/services）          Rendering（src/core/rendering, src/qml_gui/Renderer）
   │  项目、切片、预设、设备、云…       拾取、Gizmo 几何、绘制、测量、RHI 视口
   ▼
libslic3r（third_party/OrcaSlicer/src/libslic3r，打补丁后从源码编译）
```

约束：

- 业务判断放在 service / ViewModel，不放在 QML。QML 里允许简单的展示辅助函数。
- QML 不直接访问 service，统一经 ViewModel。
- `Slic3r::Model` 只由 `ProjectService` 持有，不跨线程传递指针；后台任务拷贝值或深拷贝 Model。

## 4. 服务层

| 服务 | 作用 | 真实性 |
|---|---|---|
| `ProjectService` | 持有 `Slic3r::Model`；导入、3MF 读写、对象/体/实例编辑、排布、切割、布尔、绘制数据 | 真实 |
| `SliceService` | 每盘一个持久 Print 槽，后台 `QtConcurrent` 切片、导出 G-code、结果交给预览 | 真实 |
| `PresetService` | 上游 profile 加载、继承、保存、导入导出 | 真实 |
| `UndoRedoManager`、`UndoCommands` | 基于 QUndoStack 的撤销，复杂操作用场景快照命令 | 真实 |
| `MoonrakerDeviceService` + `MdnsDiscovery`、`LanDeviceProbe`、`LanErrorCodes` | 局域网创想打印机（4408 / Moonraker），实现 `IDeviceDataPlane` | 真实，未真机验收；`Device/Backend=moonraker` 时启用 |
| `DeviceServiceMock` | 演示设备，实现 `IDeviceDataPlane` | Mock，**当前默认** |
| `CrealityAuthService`、`CrealityCloudService`、`CloudHttpClient`、`OAuthCallbackServer` | 创想云 OAuth 与账号面，实现 `ICloudDataPlane` | 真实；`Cloud/Backend=creality` 时启用 |
| `CloudServiceMock` | 演示云账号 | Mock，**当前默认** |
| `ModelLibraryBridge`、`ModelDownloadService` | 模型库网页桥（WebChannel）与下载导入 | 真实 |
| `CameraStream` / `CameraServiceMock` | FFmpeg 拉流解码 / 流状态机 | 解码真实，状态机 Mock |
| `MqttClient`、`FtpUploader`、`SsdpDiscovery` | 协议组件 | 真实 |
| `NetworkServiceMock` | 网络探测与 SSDP 发现（名字是历史遗留，行为真实） | 真实 |
| `CalibrationServiceMock` | 校准条目与向导；切片类校准有真实回读，硬件类无设备通道 | 部分真实 |
| `PluginService` | 插件启用状态持久化；安装为状态翻转 | Mock |
| `AppSettingsService` | QSettings 偏好 | 真实 |

逐项状态和移除条件见 [services-status.md](services-status.md)。设备、云、摄像头通过 `IDeviceDataPlane` / `ICloudDataPlane` / `ICameraStreamService` 接口注入，ViewModel 不依赖具体实现。

## 5. 线程

- GUI 线程：QML、ViewModel、`ProjectService` 的模型编辑。
- 渲染线程：Qt Quick 场景图；`RhiViewport` 在 `synchronize` 中从 GUI 线程拷贝场景数据（`PrepareSceneData` 脏位注册表控制上传）。
- 后台任务：切片、导出、网格简化预览、模型加载等用 `QtConcurrent::run`。结果经排队连接或带上下文对象的回调回到 GUI 线程。析构时先取消、再等待后台任务结束。

## 6. 构建产物

| 目标 | 说明 |
|---|---|
| `owzx_app_core` | OBJECT 库：core 全部代码 + `BackendContext`，App 与测试共用 |
| `owzx_qml` | STATIC 库：QML 模块 `OWzx`（`qt_add_qml_module`，qmlcachegen 字节码） |
| `OWzxSlicer` | GUI 程序 |
| `owzx-cli` | 命令行切片 |
| `PerfBench`、`owzx-render-bench` | 性能基准，结果对照 [perf-baseline.md](perf-baseline.md) |

构建只用 `scripts/auto_verify_with_vcvars.ps1`，输出到 `build/`。Qt 6.12 升级记录见 [qt612-upgrade-notes.md](qt612-upgrade-notes.md)。

头文件依赖：中文 Windows 上 `cl /showIncludes` 以 GBK 输出"注意: 包含文件:"，而 CMake 记录的前缀是 UTF-8，ninja 因此从未记录任何头文件依赖，改头文件不会重编依赖它的源文件（2026-11-03 前的构建都有此问题）。构建脚本的 `Repair-ShowIncludesPrefix` 把 `build/CMakeFiles/<版本>/CMake*Compiler.cmake` 中的前缀改为 GBK 字节；新建构建目录时脚本会自动处理。

生成头文件必须确定：`libslic3r_version.h` / `buildinfo.h` 被大部分 libslic3r 源文件包含，`SLIC3R_BUILD_ID` 因此取上游 pin 提交的日期而不是 configure 时刻（`cmake/BuildLibslic3rFromSource.cmake`）；否则每次 CMake 重跑都会重编整个 libslic3r。

## 7. 测试

由权威构建脚本依次构建并运行。主要套件：

- 行为：`ViewModelSmokeTests`、`E2EWorkflowTests`（导入 → 切片 → 预览 → 导出 → 项目存取）、`PartPlateTests`、`PreviewParserTests`、`ProjectMirrorTests`、`CliTests`
- 渲染与交互：`PrepareSceneDataTests`、`ObjectPickingTests`、`GizmoMathTests`、`GizmoGeometryTests`、`GizmoStateWiringTests`、`CameraParityTests`、`NavigatorCubeTests`、`ViewportContextMenuTests`
- QML：`QmlSmokeTests`（实例化页面）、`QmlUiAuditTests`（大量源码文本断言）、`VisualRegressionTests`（页面截图与 `tests/visual_baseline/` 对比）
- 服务：`ServiceSeamTests`、`LanDiscoveryTests`、`MoonrakerDeviceServiceTests`、`CrealityCloudConfigTests`、`CrealityCloudServiceTests`、`ModelDownloadServiceTests`、`AppToolTests`、`FlushVolCalculatorTests`

另有 `tools/qmllint_gate.py`（对照 `docs/qmllint-baseline/`）和 `tools/style_literal_gate.py`（对照 `docs/style-baseline/`）两个门禁。
