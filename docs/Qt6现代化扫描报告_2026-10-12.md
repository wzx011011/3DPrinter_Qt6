# Qt6 现代化扫描报告（2026-10-12）

> 方法：5 路并行探索代理分别扫描 C++ API 层、QML 前端、服务/网络栈、渲染/图形栈、ViewModel/应用架构；范围 `src/`（排除 third_party/build）。关键发现已逐条 file:line 验证。
> 结论去向：可执行项已合并进[开发计划](开发计划_2026-10-10.md)（S8 / X6 / 挂账新增）；本文档为证据底稿。

## 总评

**代码本体非常现代，基础设施层是短板。** 渲染、C++ API、i18n、线程模型都在 Qt 6.10 的正确姿势上（约 85-90 分）；最大的两个落后点是 **QML 构建基础设施（约 60 分）** 和 **ViewModel 的"上帝信号"架构**（后者已是审计 H3/S1，本扫描提供量化确认）。没有发现任何 Qt5 时代遗留 API。

| 功能面 | 现代度 | 一句话结论 |
|---|---|---|
| 3D 视口/渲染 | ★★★★★ | QQuickRhiItem + 裸 QRhi + qsb 着色器 + 异步 readback + 按需渲染，无需迁移只需清理 |
| C++ API 层 | ★★★★★ | 177/177 新式 connect，QRegExp/QTextCodec/foreach 零残留，QtConcurrent/QUndoStack/QSaveFile 全部正确 |
| 应用壳层 | ★★★★☆ | 无过时 HighDPI 属性、conf 驱动样式、内嵌 .qm 实时 retranslate、job object 加固 |

| i18n | ★★★★☆ | 6 语言端到端可用；复数支持为 0 |

- `QQuickWindow::setGraphicsApi`（6.3+）+ D3D11-first 预探测（RhiBackendSelector.cpp:85-239，D3D12 降级为记录在案的真机 workaround）。

- 按需渲染（无连续循环）；MSAA setSampleCount(4) 由 QQuickRhiItem 正确 resolve；缩略图 RT 单采样隔离。
- `qt_add_translations` 把 .qm 编进 exe 资源 + `engine->retranslate()` 活语言切换（6 语言 ×~1734 条）；main_qml.cpp:620-621。

## 二、P0：qt_add_qml_module 缺失（单一最大杠杆 → 计划 S8）

87 个 QML 文件经 6 个裸 `.qrc` 以源码形态进包（CMakeLists.txt:397-403），运行时逐个解析：

- **无 qmlcachegen 字节码** → 启动解析开销全保留（启动性能直接损失）。
- 无编译期 QML 类型检查；qmllint/qmlformat/.qmllint.ini 全库 0 引用（现有 QmlUiAuditTests 是正则自查）。
- 83 处 `import ".."` 相对导入 + 手写 qmldir singleton（qmldir 仅 `singleton Theme Theme.qml`）——此缺口的连锁产物。
- C++ 侧全库 **0 个 QML_ELEMENT/QML_SINGLETON**；3 个 `qmlRegisterType`（main_qml.cpp:502/504/508，带版本 URI）+ 4 个 root context property（main_qml.cpp:566 backend / :573 appSettings / :575 / :581）。
- 8 个文件被迫写带版本自定义 import（`import OWzxGL 1.0` ×5、`import OWzx.Models 1.0` ×3）。

迁移收益：字节码 + lint 进门禁 + 模块 URI + 相对 import 消亡。交互注意：qml.qrc 拆 5 份的增量编译优化被 qmlcachegen 取代（逐文件编译，增量性保留）；CI windeployqt `--qmldir`（tag-build.yml:226）需同步；`--qml-dev` 源码加载流程不受影响；QmlUiAuditTests 路径锁需与 S7 字符串锁降级协同排期。

## 六、追记：目标版本切至 Qt 6.12 LTS 后的重估（2026-10-12 同日）

升级目标 6.10 → 6.12（计划 M2.5）后，本报告结论的增量：**S8 的 context property 迁移理由降级**（Qt 6.11 起 QML 工具链正式支持 context properties，4 个 root context property 不再是 qmllint 门禁化的硬阻塞；singleton 化仍执行，理由修正为类型安全 + 模块内聚）；**新增两个 S8 后评估项**（6.12 QML Hot Reload 对 --qml-dev 迭代流的替代、qmlsc AOT 收益）；VectorImage（图标管线，协同 S6）与 Canvas Painter（SoftwareViewport 回退路径）进观察窗；StyleKit（Labs）与 Qt Quick 3D 明确不采纳。逐项明细见[开发计划 §6e 特性面重估表](开发计划_2026-10-10.md)。其余结论（各功能面打分、P0-P3 分级、挂账清单）不受目标版本变化影响。
