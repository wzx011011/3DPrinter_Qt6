## 1. 记账规则

- `[x]`：已与上游 `third_party/OrcaSlicer` 逐项对照，并有测试或端到端验证。
- `[-]`：主路径可用（真实后端、非 Mock），但未完成逐项对照，或有已登记的差距。
- `[ ]`：未开始、仅有占位，或默认路径仍是 Mock。
- 判定"完成"的四个条件缺一不可：入口可见、可操作、后端真实执行（不是 Mock 或空操作）、与上游行为一致。页面存在不等于完成。
- 每条差距写清代码位置；修掉后直接从本文删除该条（历史在 git 里），不保留"已完成"流水账。
- 新任务先登记到对应章节，再动代码。

## 5. 功能缺口

### 5.1 后端已有、界面无入口

2026-10-30 Track A 扫描 1060 个 `Q_INVOKABLE` 得出，2026-11-03 复核仍无 QML 调用。部分可能经由其他名字的入口间接使用，接线前先交叉确认：

- 对象：`arrayObject` / `arraySelectedObject`（阵列）、`resetObjectTransform`、`toggleSelectedObjectsVisibility`、`estimatePrintTimeForObject`
- 零件：`addVolumeToObject` / `deleteVolume` / `deleteObjectVolume`
- 切割：`cutObjectWithGroove`、`cutObjectWithConnectors`（可能已由 `advCutSelected` 间接调用）
- 排水孔：`appendObjectDrainHoles` 族
- 预览：`layerTimeAt` / `layerTimeCumulative`、`playAnimation` / `pauseAnimation`
- 导出：`exportPlateGCodeToPath`、`exportAllPlateGCodeToDirectory`（与菜单"全部导出"是否同一实现待确认）
- 视图：`requestFitAllPlates`
- 耗材：`autoMatchFilament`；`deleteFilamentSlot` / `mergeFilamentSlots` 仍是 stub

### 5.2 上游有、Qt 侧未承接

- 变换面板其余部分（上游 `GizmoObjectManipulation`）：旋转的相对/绝对两行、尺寸（mm）输入、贴底（drop to bed）按钮、世界/局部坐标切换。重置按钮已承接（2026-11-03）。
- 参数设置页（上游 `Tab.cpp` / `ConfigManipulation.cpp`；2026-11-03 已与安装版 OrcaSlicer 2.4.0 逐页截图对照，安装版与 pin 不一致处以 pin 源码为准）：
  - 工艺：`slicing_pipeline_plugin`（上游插件选择器，列出已安装的 slicing-pipeline 插件）未上页面，需要插件运行时（见 5.3）。
  - 打印机：没有挤出机数量设置（上游"多材料"页的 `extruders_count`，改数量时同时伸缩各挤出机参数和耗材列表）；"挤出机 1..N"页只在打印机预设本身带多个挤出机时出现。
  - `OptionToggleRules`：`enable_wrapping_detection` / `wrapping_detection_gcode` 依赖 BBL 设备能力表，这里恒隐藏；材料与工艺侧的逐挤出机/变体索引只取第 0 个（打印机"挤出机 N"页已按所显示的挤出机取值）。
  - 运行时才填充候选的开放下拉（`*_filament_id`、`support_filament` 等按耗材列表，`printhost_port` 按串口）仍是普通编辑框；定义里带候选值的（`filament_type`、`infill_anchor` 等）已是可输入的下拉。
  - 能力（`*_plugin_config_overrides`）对话框只列出预设里已存的覆盖项：上游还会列出预设中插件型选项引用的能力及其全局配置，需要插件运行时（见 5.3）。
  - 预设行：新建（+）和"更多"菜单里的 另存为 / 比较预设 是这里独有的入口（上游从预设下拉和主菜单进入），在那两处入口承接前保留。
- 准备页（2026-11-03 与安装版 OrcaSlicer 2.4.0 截图对照）：
  - 对象模式（"对象"页签）：上游工艺预设下拉在对象模式下隐藏，这里仍显示；这里多出"切片信息"头。
  - 空热床右键菜单：已对照 pin 的 `MenuFactory::create_default_menu` / `Plater::priv::on_right_click`，菜单项一致（安装版里的盘操作项、"全部替换为 3D 文件..."、"编辑盘名"不在 pin 的空白处菜单中）。唯一差异：没有选中物体时，"添加标准模型"里的"文字"/"SVG"被隐藏；上游显示并新建一个文字/SVG 对象（`GLGizmoEmboss::create_volume` / `GLGizmoSVG::create_volume`），需要 core 侧"新建文字对象"。
- 预览页未切片时：上游只显示热床与盘缩略图，图例在有 G-code 后才出现；这里右侧仍显示空图例面板（"走线类型"、`--:--` 范围）。
- 平板排除区 / 喷嘴区。
- 预览撞机标记（上游 `GCodeProcessor` conflict 结果，需切片侧先产出）。
- 上游 2026-07 后新增、尚未跟进的功能：per-object 多变体选项、3MF 导入动作对话框取消后的重入、ZIP 中文文件名导入。多喷嘴设备层（H2C/A2L `MultiNozzleSync`、`NozzleRack`）与 AMS 烘干属 BBL 设备功能，创想 LAN 设备无对应能力，承接前需先决定是否纳入范围。
- 校准六塔生成器族（引擎侧需扫描补丁，未立项）；Input Shaping 频率/阻尼与 Cornering 的几何生成。
