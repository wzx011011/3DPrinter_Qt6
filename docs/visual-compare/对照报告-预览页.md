# 预览页像素级视觉对照报告

> 日期：2026-09-02 ｜ 对照：上游 OrcaSlicer 2.4.2（Prusa.stl 已载入）vs OWzx Slicer（`--load-model Prusa.stl --open-page preview`，软件渲染模式）
> 基准图：`upstream_preview.png` / `owzx_preview.png`

## 布局结构对照

| 区域 | 上游 | OWzx | 结论 |
| ---- | ---- | ---- | ---- |
| 顶部导航 | 首页/准备/**预览**/设备/项目，预览高亮 | 同款 tab 集，预览高亮 | ✅ 一致 |
| 右上操作 | 切片单盘（灰）+ 导出G-code文件 | 切片单盘 + 导出G-code文件 | ✅ 一致（切片后同态）|
| 左侧栏 | **保留准备页的工艺侧栏**（打印机/耗材丝/工艺/质量参数树） | 同样保留工艺侧栏 | ✅ 结构一致（本轮确认）|
| 中央画布 | GL 预览画布（截图不可见） | 软件视口：空热床 + "请先切片或载入 G-code" | GL 内容两种截屏路径均不可见，内容级对比受限 |
| 底部滑条 | 层滑条（画布底部覆盖层，GL 内） | LayerSlider 独立 QML 条（缩放/分页/层号/时间） | ✅ 功能同源，形式差异（画布覆盖 vs 独立条）|
| 右侧面板 | 无独立面板（统计在画布右上 GL 覆盖层） | 分析/统计独立右面板（标准/普通、显示热床、工具位置、总时间/层数/移动/耗材/成本 + 图例） | 形式差异：OWzx 用 2D 面板呈现上游 GL 覆盖层内容 |
| 预览控件行 | 无独立行 | 预览/Summary 选择器 + 顶/前/右视角 + 适配 + 时间/层/移动 readout | OWzx 结构（对齐上游 IMSlider/视图切换功能）|

## 新发现的功能缺口

| # | 发现 | 状态 |
| ---- | ---- | ---- |
| 1 | **GUI 切片静默失败**：启动参数载入模型后，预览页点"切片单盘"无反应（G-code 不生成、无错误提示）。根因待查：startup load-model 路径可能未应用打印机配置（E2E 中切片门需要 bed/printable_area 配置，prepare 页导入路径会自动应用，startup 路径疑似绕过） | 登记，修复单独立项 |
| 2 | 修复 #1 后预览页即可对照 G-code 内容级渲染（图例色板/路径颜色/统计数值） | 依赖 #1 |

## 截图局限说明

两个应用的预览画布均为 GL/GPU 呈现，CopyFromScreen 与 DXGI 路径都只捕获到黑色区域（上游 GL 画布、OWzx 软件视口背景正常但无内容可比）。2D 骨架（导航/侧栏/面板/滑条）对照完整有效。

## 与准备页共享的已修项

耗材丝标题、参数组中文标题（层高/线宽）、行布局（标签左/值右对齐/单位尾缀/无徽章噪音）——预览页左栏同款生效。
