## 第二轮修复（2026-09-02 16:10，用户反馈"效果差很多"后）

用户对照上游参数行样式反馈差距大。探针截图定位三个真实问题并全部修复：

| # | 问题 | 修复 |
| ---- | ---- | ---- |
| 1 | 每行都渲染"工艺"来源徽章（上游无此噪音） | OptionRow sourceBadge 仅在 valueSource ≠ default 时显示；徽章车道无徽章时塌缩为 0，值编辑器紧贴标签右侧 |
| 2 | 值框空白（0.16/0.2 等值不显示） | oVal 绑定 optValue() 为一次性求值，模型异步填充后不刷新——LeftSidebar 增加 modelReset/rowsInserted → rebuildParamsFilter 重建行（值 0.12/0.20/0.25 已上屏）|
| 3 | 单位文本被徽章车道挤压截断（"mm"显示为"mg"） | 车道塌缩后单位完整显示"mm"/"mm 或 %"，与上游一致 |

**ToDesk 远程无法操作/无悬浮反馈根因与修复**：主程序强制 GPU 交换链呈现（D3D11/GL），ToDesk 虚拟显示驱动的捕获管线经常拿不到 GPU 帧——远端看到的是冻结的最后一帧（悬浮高亮、点击反馈全部"消失"，实际输入已到达）。修复：main_qml.cpp 检测 `GetSystemMetrics(SM_REMOTESESSION)`，远会话自动切换 Qt Quick 2D 软件渲染（GDI 兼容位图呈现，任何捕获管线可见）+ GLViewport 解析为 SoftwareViewport（QQuickPaintedItem，同样走软件呈现）。代价：远会话内渲染性能降低（本地会话完全不受影响）。**请通过 ToDesk 重连后验证**：窗口应可正常操作且悬浮高亮可见；3D 视口在远会话中暂为空白（软件渲染降级，属预期）。

修复后运行截图：owzx_prepare_fixed.png（值 0.12/0.20/0.25 可见、行紧凑无徽章、单位完整）。canonical 全绿：E2E 31/31、ViewModel 186/186、QML audit 174/174。
